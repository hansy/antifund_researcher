# Implementation

The public experience is signals → brief → source. Each brief explains the product idea, problem, reported advances, potential buyer and commercial hypothesis. Independent market context and unanswered questions unfold on demand. No school administration, project dashboard or chat is needed to explore an idea.

The data path is registry → discovery → immutable raw archive → classification → graph → signal hypothesis → primary-source market research → verified public projection.

Discovery covers hackathons, capstones and research across all disciplines for 2025–2026 at the 50 registry institutions. A source can describe many projects; a project can appear in multiple sources. Date-unknown and ambiguous records stay in the archive. Shared-keyword edges expose why items were grouped; Codex then assesses whether that grouping points to a common buyer problem. No graph database is needed.

Bun owns local collection and subscription-backed Codex work. Poppler preserves PDF page references. Convex stores immutable metadata revisions, collection state and the public corpus. TanStack Start serves the interface from Cloudflare Workers. Credentials and raw downloads stay out of GitHub and the public API.

The initial 26-project corpus remains available as five edited signals. New ingestion is additive for source/project evidence and archives changed signal revisions. Prepared intake publication requires verified dates and exact excerpts; collection counts never imply exhaustive coverage.

The lead integrates agent work, owns commits and deployment, runs typecheck, Bun tests, production build and a browser walkthrough, then performs one bounded autoreview and fixes accepted findings directly.
